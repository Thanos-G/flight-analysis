# Data Folder

This folder contains all datasets used throughout the project pipeline.

---

## Files

### `DelayedFlights.csv` — Raw Dataset
- **Source:** [Kaggle — Airline Delay Causes](https://www.kaggle.com/datasets/giovamata/airlinedelaycauses)
- **Records:** 1,936,758
- **Features:** 30
- **Description:** Original US Airline On-Time Performance data as downloaded from Kaggle. No modifications applied.

---

### `flight_clean.csv` — Cleaned Dataset
- **Records:** 1,928,371
- **Generated by:** `01_preprocessing.ipynb`
- **Changes applied:**
  - Null values in delay columns (`CarrierDelay`, `WeatherDelay`, `NASDelay`, `SecurityDelay`, `LateAircraftDelay`) filled with 0
  - Rows with null `ArrDelay`, `ArrTime`, `AirTime`, `ActualElapsedTime`, `TaxiIn`, `TaxiOut` dropped (cancelled flights)
  - Target variable `DELAYED` created: 1 if `ArrDelay` > 30 min, else 0
  - `DEP_PERIOD` feature added (night / morning / afternoon / evening)

---

### `flight_ml_ready.csv` — Feature-Engineered Dataset
- **Records:** 1,928,371
- **Features:** 32
- **Generated by:** `03_feature_engineering.ipynb`
- **Changes applied:**
  - Cyclical encoding for `Month` → `Month_sin`, `Month_cos`
  - Binary feature `IS_WEEKEND` added
  - IQR Capping applied to `ArrDelay` (upper bound: Q3 + 1.5×IQR)
  - Leakage features removed: `LateAircraftDelay`, `SecurityDelay`, `WeatherDelay`
  - **Used as input for:** `04_association_rules.ipynb`, `05_classification.ipynb`, `06_neural_network.ipynb`, `07_evaluation.ipynb`

---

## ⚠️ Notes

- The raw dataset `DelayedFlights.csv` is **not included** in the repository due to file size (~350MB). Download it directly from [Kaggle](https://www.kaggle.com/datasets/giovamata/airlinedelaycauses) and place it in this folder before running the notebooks.
- `flight_clean.csv` and `flight_ml_ready.csv` are included as **samples** for reference only. To reproduce the full results, generate them by running the notebooks on the complete raw dataset.
- Always run the notebooks **in order** (01 → 02 → 03 → ...) to ensure each file is generated before it is needed.
